# Olist Customer Segmentation

Este diretório tem como objetivo realizar a **clusterização de clientes** utilizando os dados disponibilizados pela Olist no desafio do Kaggle, disponível neste link:  
👉 [https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Notebooks

- **olist_customer_segmentation.ipynb**:  
  Desenvolvido com **PySpark**, este notebook teve como principal objetivo explorar as ferramentas de *Machine Learning* disponíveis no Spark. ⚠️ **A execução não foi finalizada**, sendo um experimento para estudo da tecnologia.

- **olist_cutomer_cluster_pandas.ipynb**:  
  Contém a análise de clusterização feita com **Pandas** e outras bibliotecas do ecossistema Python. Este notebook apresenta uma execução mais completa do processo.
